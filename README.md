# Smart AI Assistant

A Python-based AI assistant that can answer questions, perform calculations, provide the current date and time, and maintain conversation history.

## Features

- Answer general questions using an AI model
- Perform basic calculations
- Get the current date and time
- Maintain conversation history
- Clear the conversation when needed
- Interactive command-line interface

## Technologies

- Python
- LangChain
- LangGraph
- OpenAI API
- python-dotenv
